## 🟨 3장. 자바스크립트 개발 환경과 실행 방법

> 3장 내용은 어떻게 실행하는지, 환경은 어떻게 구성하는지에 대한 내용이 주를 이뤄서 필요한 내용만 정리했다.

### 1️⃣ 웹 브라우저

#### 1) 크롬 개발자도구

|패널|설명|
|--|---|
|Elements|로딩된 웹페이지의 DOM, CSS를 편집해서 렌더링된 뷰를 확인해볼 수 있음. 단, 편집한 내용이 저장되지는 않음.|
|Console|로딩된 웹페이지의 에러를 확인하거나 자바스크립트 소스코드에 작성한 console.log 메서드 실행 결과 확인|
|Sources|로딩된 웹페이지의 자바스크립트 코드를 디버깅 할 수 있음|
|Network|로딩된 웹페이지에 관련된 네트워크 요청 정보와 성능을 확인할 수 있음|
|Application|웹 스토리지, 세션, 쿠키를 확인하고 관리할수 있음|

#### 2) 디버깅 `Sources`
1. 에러가 발생한 코드 위치에 빨간 밑줄이 표시되고, 그 위에 마우스를 올려보면 에러 정보가 표시된다.
2. 에러가 발생한 코드 왼쪽의 라인 번호를 클릭해 브레이크포인트(중단점)를 걸고 다시 버튼을 클릭하면 디버깅 모드로 들어간다.
3. 변수에 커서를 올리면 값을 확인할 수 있다.
