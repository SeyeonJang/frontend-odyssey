## Chapter 03. First Components

### Hello World 코드
```html
<!doctype html>
<html lang="kr">
<head>
    <meta charset="UTF-8">
    <meta name="viewport"
          content="width=device-width, user-scalable=no, initial-scale=1.0, maximum-scale=1.0, minimum-scale=1.0">
    <meta http-equiv="X-UA-Compatible" content="ie=edge">
    <title>Hello World</title>
    <script src="https://cdnjs.cloudflare.com/ajax/libs/react/15.3.1/react.min.js"></script>
    <script src="https://unpkg.com/babel-standalone@6/babel.min.hs"></script>
</head>
<body>
    <div id="app"></div>
    <script type="text/babel">
        var app = <hi>Hello World</hi>
        var mountComponent = document.querySelector('#app');
        ReactDOM.render(app.mountComponent);
    </script>
</body>
</html>
```

### 1️⃣ Loading the React Library

`<script>` 태그는 `<head>` 요소 안에 넣어야 한다.<br> 
React 애플리케이션을 작성하기 전에 `<script>` 로딩 태그를 먼저 배치하는 것이 중요하다.
그렇지 않으면 `React`와 `ReactDOM` 변수가 우리가 사용하기 전에 제때 정의되지 않게 된다.

위 코드에서, `<head>` 안에는 `babel-core`라는 라이브러리를 포함하는 `<script>` 태그도 있다. babel-core란 무엇일까?
<br>

### 2️⃣ Babel

Babel은 ES6 코드를 ES5로 변환하는 도구로, 더 많은 브라우저에서 코드가 동작하게 해준다.

`<body>` 안의 `<script type="text/babel">` 부분이 React 앱 코드이다. `type="text/babel"`은 Babel이 해당 스크립트를 실행 전에 변환하라는 신호이다.<br>
여기서는 `<h1>Hello world</h1>` 하나를 렌더링한다. `ReactDOM.render()` 함수는 무엇을, 어디에 렌더링할지 지정한다.
