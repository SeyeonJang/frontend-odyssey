## Chapter 02. What is JSX? ES6?

### 1️⃣ JSX/ES5/ES6 ??!

`ES5`(ECMAScript5)는 `일반적인 자바스크립트`이다. 자바스크립트의 다섯번째 버전으로, 2009년에 최종 확정되어 몇 년 전부터 주요 브라우저에서 모두 지원되고 있다. 따라서 _최근에 작성하거나 본 JavaScript는 대부분 ES5일 가능성이 높다_.<br>

`ES6`(ECMAScript6)는 2015년에 최종 확정된 자바스크립트의 새로운 버전으로, 더 깔끔한 문법과 기능적인 추가 요소들을 제공한다. 하지만, Internet Explorer 11같은 구버전 브라우저들은 지원하지 않기도 한다.

`JSX`는 JavaScript XML의 줄임말이다. React에서는 HTML처럼 보이는 JavaScript 문법으로 UI를 선언할 수 있게 해준다.

```javascript
<h1>Hello World</h1> <!-- jsx -->
React.createElement('h1', {classname:'large'}, 'Hello World'); <!-- js -->
```

### 2️⃣ Hello World

#### JSX 예시1 )

HTML 태그를 React 컴포넌트를 JSX로 하나 만들면 다음과 같다.<br> 
일반 JS에서는 요소를 생성하려면 `React.createElement()` 같은 복잡한 문법을 써야하지만, JSX를 사용하면 `<h1>Hello</h1>`처럼 HTML로 보이는 코드를 간단하게 쓸 수 있다.

```javascript
class HelloWorld extends React.Component {
    render() {
        return (
            <h1 className="large">Hello World</h1>
        );
    }
}
```

컴포넌트 안의 함수는 마치 HTML을 반환하는 것처럼 보이지만, 실제로는 JSX다. JSX는 런타임 시점에 일반 JavaScript로 변환되고 해당 컴포넌트는 변환된 뒤 다음과 같은 형태가 된다.

```javascript
class HelloWorld extends React.Component {
    render() {
        return (
            React.createElement(
                'h1',
                {className: 'large'},
                'Hello World'
            )
        );
    }
}
```

JSX는 HTML처럼 보이지만 실제로는 선언문을 더 간결하게 작성하는 방식일 뿐이다. 컴포넌트가 렌더링되면 실제 HTML 요소의 가상 표현인 React 요소 트리(virtual DOM)를 반환한다.

위 내용은 ES6 문법으로 만들어져있고, 이를 ES5 문법으로 바꾸면 다음과 같다.

```javascript
var HelloWorld = function() {};
HelloWorld.prototype.render = function() {
    return React.createElement('h1', { className: 'large' }, 'Hello World');
};
Object.extend(HelloWorld, React.Component);
```

#### JSX 예시2 )

JSX로 복잡한 컴포넌트를 만들면 가독성이 좋다. 아래 예시와 같이 만들 수 있다.
```javascript
<div>
    <img src="profile.jpg" alt="Profile photo"/>
    <h1>Welcome back Ari</h1>
</div>
```

그리고 JavaScript는 브라우저로 아래와 같이 전달한다.
```javascript
React.createElement("div", null,
    React.createElement("img", {src: "profile.jpg", alt: "Profile photo"}),
    React.createElement("h1", null, "Welcome back Ari")
);
```

### 🧐 Today I Learned

1. React라고 일반 HTML과 엄청 다른 게 아니다.

JSX는 HTML처럼 보이지만 실제로는 선언문을 더 간결하게 작성하는 방식일 뿐이다. JavaScript로 컴포넌트가 렌더링되면 실제 HTML 요소의 가상 표현인 React 요소 트리(virtual DOM)를 반환한다는 점을 처음 알았다.

2. JSX의 정확한 의미

JavaScript + XML 을 의미하는 JSX는 HTML처럼 보이는 JavaScript 문법으로 UI를 선언하게 해주는 것이다. 1과 연결되어서 JSX로 간편하게 html 코드를 `React.createElement()`라는 복잡함 없이 작성할 수 있다.
